# The Making Room Lite — free one-page template for craft workshop studios

A single-file HTML template for a craft workshop studio: warm, hands-on,
artisanal, with smooth scrolling (Lenis) and scroll-triggered animation.
No build step, no frameworks — open `index.html` and edit.

**Live demo:** https://makingroom-lite.vercel.app

## Quick start

1. Edit the text directly in `index.html` — studio name, the three crafts,
   the review, your address and contact details.
2. Replace the photos in `img/` with your own (keep the filenames, or update the `src` paths).
3. Point the "Ask About a Place" buttons at your own email address or contact form.
4. Upload anywhere — it's static files. Vercel, Netlify and GitHub Pages host it free.
